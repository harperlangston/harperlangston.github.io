\subsection{Detailed Description}
\subsubsection*{template$<$class F$>$ class Num\-Tns$<$ F $>$}

Num\-Tns is a three-dimensional tensor made up of a size and data. The data can be made up of any type (ints, double, bools, etc.). Like {\bf Num\-Mat}{\rm (p.\,\pageref{classNumMat})} but has extra size. 

Num\-Tns is a way to organize 3D cartesian structure. This is seen mainly in fmm3d.cpp and fmm3d\_\-mpi.cpp for use with the Upward Equivalent to Upward Check structure (Upw\-Equ2Upw\-Chk). Here, the different matrices are from different child to the parent box. Different children are organized as a 2$\ast$2$\ast$2 tensor. See fmm3d\_\-mpi.cpp for more information.
